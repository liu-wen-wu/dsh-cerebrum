> 素材：dshopen 索引 + `cdn.dsh.so/market/top-rank.json`（1200 条实时榜单）+ 14 个代表性仓库 README（`research/oss/pets/*.md`）。榜单里的大肥鱼生态：
> `dsh-dafeiyu`（rank 51，509★，2.4 万下载）· `dsh-persona-dafeiyu`（rank 214，59★）· `dafeiyu-buchibaifan`（rank 612）· `dsh-bigfish`（rank 614）· `dsh-memraw`（rank 1054，新品）。

## 1. 现有桌面宠物插件的解剖（它们实际是怎么工作的）

读下来，所有宠物插件都是同一个骨架，差别只在每个零件做得多深：

```
┌────────────────────────── 宠物插件 = 外壳(shell) ──────────────────────────┐
│ ① 形象资产         sprite 图集 / Live2D 模型(.model3.json) / 逐帧 webm    │
│ ② 渲染与物理       浏览器 overlay(事件穿透) / Electron-Tauri 透明置顶窗      │
│ ③ 输入             点击(摸头) / 拖拽甩抛 / 喂食 / 右键菜单 / 对话输入框      │
│ ④ 输出             气泡台词 / 语音包 / 系统通知                             │
│ ⑤ 事件状态机       session/event → 状态 → 动画映射（思考/工作/等待/成功/出错）│
│ ⑥ 配置与存储       config.jsonc / localStorage / ~/.dsh/... 私有目录        │
└────────────────────────────────────────────────────────────────────────────┘
```

**结论**：现有插件把「外壳」卷到了极致（动画、物理、双端、Live2D、素材流水线），但「灵魂」普遍只有三样薄薄的替代品：好感度计数器（+1/+5）、memory.json 聊天记录、静态人设文案。没有一家做了 appraisal 情绪、神经调质、跨会话情景记忆、性格参数化。

**但大肥鱼生态自己长出了一个重要事实**：完整的角色不是"一个插件"，而是**四个插件各占一层拼出来的**——`dsh-dafeiyu`（形象/模型层）+ `dsh-persona-dafeiyu`（人设/性格层）+ `dsh-memraw`（记忆层）+ 各插件的互动（逻辑/情感层）。市场已经用脚投票回答了"完整宠物 = 什么"。

## 2. 一个完整的角色/宠物 = 四层，缺一不可

| 层 | 回答的问题 | 最小完备清单 |
|---|---|---|
| **① 模型（外壳）** | 它长什么样、怎么动、怎么说 | 形象资产（Live2D/sprite/frames）；表情×情绪映射表；动作库×状态映射；声线（voice.json/TTS）；立绘版权 |
| **② 记忆** | 它记得什么、忘了什么 | 三层：对话上下文（工作记忆）→ 跨会话情景记忆（发生过什么、说过什么、承诺过什么）→ 语义记忆（用户偏好、世界观/世界书）。**必须有遗忘曲线**，否则记性好的宠物也会变成复读机 |
| **③ 逻辑** | 它怎么反应、怎么决策 | 事件→状态→动画的状态机；互动规则（摸头/喂食/冷却/等级）；行为选择（动画链权重、台词库、主动提议）；**判断**（什么时候碎碎念、说什么、要不要提醒用户） |
| **④ 情感** | 它"感觉"如何 | 核心情感（效价/唤醒/支配）→ 表情映射；情绪事件（摸头→开心，批评→低落）；**心境**（慢变量，冷落会慢慢低落）；好感度（不是计数器，而是"与用户的互动史"的积分）；需求（饥饿/精力/陪伴） |

四层的正确关系是：**事件 → 评价(情感) → 状态(逻辑) → 表情/动作(模型)，同时写入记忆；记忆反过来塑造性格和下一次评价**。现有插件缺的正是这个闭环，它们只有「事件 → 状态 → 动画」一条直线。

## 2.5 记忆哲学的对立：dsh-memraw 的「永不遗忘」 vs 我们的「幂律遗忘」

dsh-memraw 提出了与 dsh-cerebrum 相反的立场，值得认真对待：

| | dsh-memraw | dsh-cerebrum（我们） |
|---|---|---|
| 底座 | **原文全量**：每个 `session/event` 一字不改进 SQLite，只 INSERT 不 UPDATE/DELETE | 情景摘要 + 概念 + 幂律遗忘（旧事会淡出） |
| 检索 | FTS5 + 坐标回读原话（`session#seq`） | SDR/BM25/CA3 补全/ACT-R，返回摘要 |
| 注入 | **零逐轮注入**：常驻指引 300 token + 首轮引导 + 按需工具 | 常驻层 + 单胜者情节注入 |
| 体积 | 随对话线性增长，靠冷归档不删 | 容量上限 + 剪枝，稳定在 ~10MB |
| 可验证性 | 摘要/切片全可回溯重建 | 记忆可导出但原文不存 |

**正确的结论是两者都要**：memraw 是"底稿"，cerebrum 是"印象"。
- 证据与细节 → 原文底稿（永不丢，按坐标可查，回答"具体哪天哪句话"）；
- 优先级与联想 → 遗忘曲线（决定"什么该被想起来"，防止上下文被旧事淹没）。
大脑正是这样工作的：海马/皮层的记忆会失真、会遗忘，但外部记录（笔记/日志）提供可核对的底稿。一个完整的宠物应该像人一样——**印象会淡，但证据在**。我们的路线图已加上：episode 增加 `rawRefs`（`session#seq` 坐标），对接 memraw 或自存原文指针。

## 3. 缺的那块"大脑"，dsh-cerebrum 正好是现成的

我们之前做的东西，恰好就是宠物缺的四层灵魂。直接接线：

### 3.1 情感层（dsh-cerebrum 已有）
- **互动 = appraisal 事件**：摸头 → `appraise({congruence:+0.5, agency:0, control:0.6})` → 感激/喜悦 → 表情+台词；批评/出错 → 挫败 → 低落动画；喂食 → joy + DA↑（多巴胺=奖励）。
- **冷落 = 心境自然衰减**：`affect.decay()` 已经把效价/唤醒/支配慢慢拉回人格设定点——宠物"长时间不理它会闷"是内置行为。
- **情绪 → 表情映射**：15 个情绪原型（喜悦/感激/自豪/挫败/焦虑/平静…）直接映射到 Live2D expressions / 贴纸 mood。
- **好感度 = 互动史积分**：不要 +1/+5 计数器，用 `gratitude/joy` 情绪计数 + 社会温暖（Extraversion×Agreeableness）+ 共同经历的效价累计。cerebrum 的 self.counters.emotions 已经在记。

### 3.2 性格层（dsh-cerebrum 已有）
六种二次元人设 = Big Five 的 4 个 preset + 参数化，一一对应：

| 人设 | Big Five 映射 | 效果 |
|---|---|---|
| 元气 | E↑ O↑ | 碎碎念高频、主动提议、verbosity↑ |
| 傲娇 | A↓ E↑ | 感谢时说反话：高 gratitude 但低 socialWarmth 措辞 |
| 三无 | E↓ N↓ | 极少主动、短句、情绪振幅小 |
| 天然呆 | O↑ C↓ | 好奇驱动、计划性差 |
| 温柔治愈 | A↑ N↓ | 高频共情、安慰性措辞 |
| 病娇 | A↓ N↑ | 高威胁敏感、被冷落时 valence 剧降（rumination 高） |

`personality.params()` 的 verbosity/exploration/rumination 直接驱动台词选择与主动行为频率。

（工程上可直接抄 dsh-persona-dafeiyu 的两个做法：人设段落的 `text` 用**动态函数**实现免重启切换；**全局/工作区/会话三档作用域**。它注册的 UI 席位是 `settings.section` / `conversation.composer.dock` / `shell.overlay` / `conversation.hero.options`——将来给我们自己的性格面板用。）

### 3.3 记忆层（dsh-cerebrum 已有）
- 对话上下文：把宠物聊天的每一轮喂给 `cerebrum_remember`（或走 session/event 自动捕获）；
- 用户偏好 = resident 层（"主人讨厌香菜"永远记得，且每轮注入）；
- 世界观/角色设定 = semantic 记忆 + `self.identity`；
- 幂律遗忘保证宠物不会变成无限膨胀的记事本（普通琐事 20 年后剩 2–8%，重要约定进 permastore 54%）。

### 3.4 逻辑层（dsh-cerebrum 已有）
- 状态机外壳保留（session/event → 工作状态动画）；
- 碎碎念内容选择 = `judge`（什么时候说、说什么：按探索率/verbosity 决定要不要主动开口，按 mood 决定语气）；
- 判断/行动倾向 = judge 的 `choice + confidence + gut`，宠物可以"想提醒你余额不足"时先内部判断再开口。

### 3.5 接线方式（DSH 插件之间怎么连）
- 宿主侧：宠物插件 `ctx.get('cerebrum')`（我们的插件已经把服务 provide 出来了）直接读 `state()` / 调 `appraise()`；
- 或者走工具：宠物插件注册 `cerebrum_state` 的轮询，或通过我们暴露的服务方法；
- 事件：宠物继续订阅 `session/event`，但把「状态→动画」升级为「事件 → cerebrum 评价 → 情绪 → 表情 + 动画」。

## 4. 一张图总结

```

        ┌─────────────────────────────┼─────────────────────────────┐

        ▼                       记忆三层 + 幂律遗忘                    │

        │                             │                               │
        ├───────────► 性格(Big Five) ◄─┘（性格是长期设定点）           │
        ▼                             ▼                               │
   表情/贴纸/Live2D表达式      judge：何时说话、说什么、语气             │
```

**一句话**：现有桌宠插件缺的不是动画，是大脑；把 dsh-cerebrum 接上任何一个 pet shell（推荐 dsh-pet 的 Cordis 通道 `ctx.get('petApi7340')` 或注册表式 pet），"外壳 + 大脑"就是一只完整的宠物。
